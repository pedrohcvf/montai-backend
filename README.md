# Montaí

Marketplace regional de hardware: lojas verificadas vendem peças novas, pessoas físicas vendem usadas, e o pagamento fica retido até a retirada em mãos ser confirmada por código.

> 🚧 **Em construção.** Fase 0 (fundação) em andamento.

## Stack

Java 21 · Spring Boot 4.1 · Maven · Spring Modulith · Spring Security (JWT) · PostgreSQL · Flyway · Docker Compose
